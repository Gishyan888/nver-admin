## Nvér specs

What Nvér has to do, and the task cards, are in the folder `specs/`. It is a separate git repository that this one ignores; it is brought up to date at the start of every session.

- Before building anything, find its task card in `specs/features/<group>/F-XX-<name>/tasks.md` and build what the card says.
- The rules for working with the specs follow. Every path in them starts at `specs/`: `features/…` means `specs/features/…`, and `team/devlog.py` means `specs/team/devlog.py`.
- Code is committed and pushed in this repository as usual. The result of a task goes to the spec repository with `python3 specs/team/result.py` (see the rules below).
